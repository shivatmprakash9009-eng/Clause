## 18. Contributing

**Branching.** `main` protected; feature branches `feat/…`, `fix/…`, `docs/…`; pull requests require a passing gate.
**Commits.** Conventional style: `feat(hero): draw highlighter on load`. One concern per commit.
**Code style.** TypeScript strict; no `any` without a comment; components small and typed; no inline marketing copy; no raw design values; accessibility attributes mandatory for new interactive elements.
**Pull request checklist.** ☐ lint/typecheck/build ☐ gate ☐ new tokens documented ☐ reduced-motion fallback ☐ keyboard and focus ☐ both themes ☐ docs updated ☐ `feature.json` updated with evidence.
**Definition of ready** for a new section: copy approved, tokens identified, motion table written, accessibility notes, test steps.
